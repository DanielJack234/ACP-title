Sticky Positioning property

This is a hybrid of relative and fixed positioning. The element is treated as relative until the user's scroll position reaches a specified threshold (e.g., top: 0;), at which point it becomes "stuck" in that position, behaving like a fixed element. This requires at least one offset property to be set to a non-auto value to work correctly.

Relative Positioning property
An element with position: relative; is positioned relative to its normal position in the document flow. The space the element originally occupied is preserved, and using offset properties (e.g., top: 20px;) "nudges" it from its original location without affecting the layout of other elements
